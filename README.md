✕ Tic · Tac · Toe
A Python implementation of the classic Tic-Tac-Toe game with two interfaces — a sleek dark-themed GUI built with Tkinter and a lightweight terminal-based CLI version.

📋 Features
GUI Version

Dark neon-themed UI with custom color palette
Smooth grid layout with hover effects
Live scoreboard tracking wins and draws across rounds
Visual highlights on winning combinations
✕ and ○ symbols with distinct neon colors
"New Game" button to reset without losing score history

CLI Version

Simple text-based board rendered in the terminal
Input validation with error handling
Automatic win and draw detection
Numbered positions (1–9) for easy move entry


🚀 Getting Started
Prerequisites

Python 3.x
Tkinter (included with most Python installations)
🎮 How to Play--------

1. The game is played on a 3×3 grid.
2. Player ✕ always goes first.
3. Players take turns placing their symbol on an empty cell.
4. First player to get 3 in a row — horizontally, vertically, or diagonally — wins!
5. If all 9 cells are filled with no winner, it's a Draw.
6. Click New Game (GUI) or restart the script (CLI) to play again.
